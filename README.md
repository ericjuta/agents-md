# agents-md

My cross-project working agreement for coding agents.

[AGENTS.md](AGENTS.md) holds the always-on preferences I run in oh-my-pi with Claude. Repository setup, command recipes, and project-specific procedures belong in workspace instructions or task-specific skills. Personal and project-specific details are left out.

[docs/rationale.md](docs/rationale.md) explains, rule by rule, why each instruction earns its place.

## What it covers

- How to read short messages for intent instead of literal wording.
- How far a grant of authority reaches, and which limits stay in force.
- Finish the requested work, verify it, and stop at the agreed scope.
- Keep evidence honest: live state outranks memory and summaries.
- Write for people who have zero context.

## Use it

1. Read [AGENTS.md](AGENTS.md) and adapt it to your tools, permissions, and workflow.
2. Merge the parts you want into your existing global agent instructions rather than overwriting them.
3. Keep project rules in each repository's own `AGENTS.md`.

The **Second brain** section describes my private notes setup, which is not included here. Replace or remove that section, and define your own authorization boundaries rather than inheriting mine.

These are personal operating preferences, not an official template or a benchmarked claim of better model performance.
